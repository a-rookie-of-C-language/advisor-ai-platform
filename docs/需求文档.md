# 辅导员智能支持平台 - 学生管理模块需求文档

> 版本：v1.0
> 日期：2026-05-07
> 状态：草稿

---

## 1. 文档目的

本文档为辅导员智能支持平台学生管理相关模块的需求说明书，旨在明确各模块的业务范围、功能边界、数据对象、角色权限及后续扩展规划，作为后续设计开发的核心依据。

---

## 2. 项目背景

### 2.1 项目定位

辅导员智能支持平台旨在帮助高校辅导员减轻日常工作负担，通过信息化手段实现学生档案管理、宿舍管理、课堂考勤联动、学业管理等业务的线上化，提升辅导员对学生状态的感知能力和处置效率。

### 2.2 现有系统能力

平台现有能力包括：

- AI 对话（chat-service）
- 知识库检索增强（rag-service）
- 会话记忆（memory-service）
- 审计日志（audit-service）
- 风控链路（risk-control-service）
- 统一网关（gateway）
- 认证授权（auth-service）

本次新增模块将围绕"学生"这一主业务对象，构建独立的学生管理服务体系。

---

## 3. 整体规划

### 3.1 模块规划

| 序号 | 模块名称 | 阶段 | 说明 |
|------|----------|------|------|
| 1 | 学生管理 | 一期 | 核心模块，完整落地 |
| 2 | 宿舍管理 | 一期 | 核心模块，完整落地 |
| 3 | 课堂考勤管理 | 一期 | 接入现有打卡模块，独立完整功能 |
| 4 | 学业管理 | 一期预留 | 预留数据模型和基础看板，后续扩展 |
| 5 | 学生心理 | 后续 | 后期纳入 |
| 6 | 食堂 | 后续 | 后期纳入 |
| 7 | 二课 | 暂不做 | 明确不纳入 |

### 3.2 建设原则

- **学生主线**：以"学生"作为核心业务对象，所有模块围绕学生组织数据与流程
- **双角色**：一期只区分"辅导员"和"管理员"两种角色
- **独立模块**：各模块独立开发、部署，前端独立入口
- **可扩展**：数据模型预留扩展字段，为后续状态域接入提供基础

## 4. 一期模块详细需求

---

### 4.1 学生管理

#### 4.1.1 业务目标

通过 Excel 批量导入建立学生档案，支撑信息缺失等异常检测与待办生成，为辅导员提供学生档案管理、待办处理、统计汇总能力，并预留与 AI 对话（chat）模块联动的能力。

#### 4.1.2 试点范围

按辅导员归属的班级进行试点，暂不限定学院和全校范围。

#### 4.1.3 数据来源

以 Excel 导入为主，人工维护为辅。后续逐步对接教务系统、学工系统。

#### 4.1.4 学生归属

- 学生归属班级
- 班级归属辅导员
- 班级归属后续可由管理员调整

#### 4.1.5 学生档案字段

**学籍基础（必填）：**

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 学号 | 学生唯一标识 | 唯一约束 |
| 姓名 | 学生姓名 | 必填 |
| 性别 | 男/女 | 必填 |
| 年级 | 如 2023 | 必填 |
| 专业 | 专业名称 | 必填 |
| 班级 | 班级编码 | 必填 |

**联系方式（选填）：**

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 手机号 | 学生手机号 | 可空 |
| 邮箱 | 学生邮箱 | 可空 |
| 宿舍 | 宿舍地址 | 可空 |
| 紧急联系人 | 紧急联系人姓名及电话 | 可空 |

**管理字段：**

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 辅导员工号 | 责任辅导员账号 | 必填 |
| 备注 | 补充说明 | 选填 |

#### 4.1.6 主键与去重

- 主键：系统自增 ID
- 业务唯一键：学号（唯一约束）
- 去重规则：按学号判断重复

#### 4.1.7 Excel 导入规则

- 提供 Excel 模板下载
- 支持网页上传 Excel
- 必填校验：学号、班级、辅导员工号
- 重复处理：学号重复时，由用户选择覆盖或跳过（默认覆盖）
- 导入结果：返回成功/失败明细，包括失败原因和行号
- 重复数据提示：列出重复学号明细
- 导入统计：返回成功数、失败数、重复数

#### 4.1.8 异常检测

**信息缺失：**

- 触发条件：联系方式字段为空（手机号、邮箱、宿舍、紧急联系人全部为空）
- 处理方式：自动生成待办任务，归属给对应辅导员
- 展示方式：学生列表高亮异常状态

**人工补充：**

- 管理员可手工标记其他异常
- 预留异常规则可配置能力（前端预留配置入口）

#### 4.1.9 待办管理

**待办状态（标准四态）：**

- 待处理
- 处理中
- 已完成
- 已关闭

**待办生成规则：**

- 信息缺失时自动生成待办
- 归属给班级对应的辅导员

**待办操作：**

- 创建任务
- 编辑档案
- 状态流转

**待办可见范围：**

- 辅导员：只能看本人负责的待办
- 管理员：可看全部待办

#### 4.1.10 历史留痕

**学期快照：**

- 按学期保留学生档案快照
- 快照内容包括：档案完整内容、快照时间、快照类型

**批次历史：**

- 每次导入记录批次信息
- 记录内容：上传人、上传时间、文件名、统计信息、重复明细、失败原因

**字段变更留痕：**

- 修改前后值
- 修改人及修改时间
- 修改原因
- 批次号

#### 4.1.11 页面与功能

**前端模块名称：** 学生管理（独立入口）

**页面组成（单页集成）：**

- 学生列表页
  - 列表展示
  - 筛选：班级、辅导员、异常类型、处理状态
  - 学生详情弹窗
  - 批量操作：导入、导出、创建待办、分配辅导员
  - 列表高亮信息缺失学生
- 导入页面
  - Excel 模板下载
  - 网页上传
  - 导入结果展示
  - 导入历史记录
- 统计报表页
  - 概览统计：总学生数、已建档数、待办数
  - 缺失统计：信息缺失人数
  - 导出：学生档案、待办清单、筛选结果

**学生详情弹窗内容：**

- 基础档案
- 待办流转记录

#### 4.1.12 导出功能

- 导出内容：学生档案、待办清单、统计汇总
- 导出权限：按可见范围导出（辅导员导本人范围，管理员可导全部）

#### 4.1.13 权限

- 访问角色：辅导员、管理员
- 数据可见范围：按学生归属的辅导员划分
- 编辑权限：管理员主维护

#### 4.1.14 联动能力

**风控接入（写入校验）：**

- 学生档案新增、编辑、导入时过风控

**审计接入：**

- 待办状态流转写入 audit-service

**Chat 联动（预留）：**

- 预留 Agent 工具调用接口
- 后续 chat 可查询学生基础档案、待办状态、历史快照
- 联系方式在发送给 agent 时脱敏

#### 4.1.15 扩展预留

**按领域分表：**

- 当前只做学生基础档案
- 后续出勤、心理、学业等状态域独立建模
- 主学生表与状态域表通过学号关联

### 4.2 宿舍管理

#### 4.2.1 业务目标

实现宿舍结构管理、住宿分配、宿舍异常处理、宿舍检查记录的全流程线上化，并支持按寝室归属关联学生。

#### 4.2.2 数据对象

**宿舍结构：**

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 楼栋 | 楼栋编号或名称 | 必填 |
| 楼层 | 楼层编号 | 必填 |
| 寝室 | 寝室编号 | 必填 |
| 床位数 | 床位总数 | 必填 |
| 已入住数 | 当前入住人数 | 系统计算 |

**入住变更：**

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 学号 | 学生学号 | 必填 |
| 楼栋 | 楼栋编号 | 必填 |
| 寝室 | 寝室编号 | 必填 |
| 床位号 | 具体床位 | 必填 |
| 入住日期 | 入住时间 | 必填 |
| 变更类型 | 入住/调宿/退宿 | 必填 |

**宿舍异常：**

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 异常类型 | 晚归、未归、违纪等 | 必填 |
| 发生日期 | 异常发生时间 | 必填 |
| 学生学号 | 关联学生 | 必填 |
| 寝室 | 异常寝室 | 必填 |
| 处理状态 | 待处理/处理中/已完成/已关闭 | 必填 |
| 处理人 | 处理辅导员 | 必填 |
| 处理备注 | 处理说明 | 选填 |

**宿舍检查：**

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 检查日期 | 检查时间 | 必填 |
| 寝室 | 被检查寝室 | 必填 |
| 检查结果 | 合格/不合格 | 必填 |
| 异常描述 | 不合格说明 | 选填 |
| 检查人 | 检查教师 | 必填 |

#### 4.2.3 归属关系

- 宿舍归属到寝室（楼栋-楼层-寝室）
- 学生归属到寝室（可查学生当前住宿信息）
- 预留班级与宿舍归属的映射关系

#### 4.2.4 页面与功能

**前端模块名称：** 宿舍管理（独立入口）

**页面组成：**

- 宿舍结构管理页
  - 楼栋/楼层/寝室列表
  - 新增/编辑/删除寝室
- 住宿管理页
  - 入住登记
  - 调宿办理
  - 退宿登记
  - 当前住宿查询
- 宿舍异常管理页
  - 异常登记
  - 异常列表
  - 状态流转
  - 处理记录
- 宿舍检查页
  - 检查记录登记
  - 检查历史查询
  - 统计报表

#### 4.2.5 权限

- 访问角色：辅导员、管理员
- 操作权限：辅导员主操作，管理员可查看全部和做全局调整

### 4.3 课堂考勤管理

#### 4.3.1 业务目标

对接现有课堂打卡模块（已在开发），实现考勤数据接入、考勤明细管理、班级考勤看板、异常处理的全流程线上化，并支持与学生详情联动展示考勤概览，同时为 AI Agent 查询学生考勤记录预留接口能力。

#### 4.3.2 数据来源

- 对接现有打卡模块的结果数据（已在开发）
- 接入内容：打卡结果、考勤状态、异常处理结果
- 后续可扩展：对接教务系统自动同步课程和考勤规则

#### 4.3.3 数据对象

**考勤记录：**

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 学号 | 学生学号 | 必填，关联学生档案 |
| 姓名 | 学生姓名 | 从学生档案关联 |
| 班级编码 | 班级编号 | 必填 |
| 课程名称 | 课程名 | 必填 |
| 考勤日期 | 考勤发生的日期 | 必填 |
| 考勤状态 | 正常/迟到/缺勤/早退/请假 | 必填 |
| 打卡时间 | 实际打卡时间 | 选填 |
| 备注 | 补充说明 | 选填 |

**考勤异常处理记录：**

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 学号 | 学生学号 | 必填 |
| 考勤日期 | 异常考勤日期 | 必填 |
| 异常类型 | 迟到/缺勤/早退 | 必填 |
| 处理状态 | 待处理/处理中/已完成/已关闭 | 必填 |
| 处理人 | 处理辅导员工号 | 必填 |
| 处理备注 | 处理说明 | 选填 |
| 处理时间 | 处理完成时间 | 选填 |

#### 4.3.4 考勤状态定义

| 状态 | 说明 | 颜色标识（前端） |
|------|------|----------------|
| 正常 | 按规定时间打卡 | 绿色 |
| 迟到 | 超过规定时间打卡 | 橙色 |
| 缺勤 | 未打卡且无请假 | 红色 |
| 早退 | 提前离开 | 橙色 |
| 请假 | 已请假并审批 | 蓝色 |

#### 4.3.5 异常检测规则

- **连续缺勤预警**：同一学生同一课程连续缺勤 3 次以上，自动生成待办并提醒辅导员
- **月度缺勤率预警**：学生月度缺勤率超过 20%，自动生成预警待办
- **班级缺勤率看板**：按班级统计月度缺勤率，超过阈值高亮显示

#### 4.3.6 页面与功能

**前端模块名称：** 课堂考勤（独立入口）

**页面组成：**

- **考勤总览页**
  - 全校/全院考勤率趋势图（按天/周/月）
  - 各班级考勤率排名
  - 异常考勤学生名单
  - 今日考勤快报

- **考勤明细页**
  - 学生考勤记录列表
  - 筛选：班级、学号、姓名、课程、日期范围、考勤状态
  - 导出考勤记录

- **异常处理页**
  - 异常考勤列表（迟到/缺勤/早退）
  - 异常登记与编辑
  - 状态流转：待处理 → 处理中 → 已完成 → 已关闭
  - 处理记录展示

- **班级考勤看板页**
  - 按班级查看考勤率、出勤率、缺勤率、迟到率
  - 班级间横向对比
  - 时间维度趋势（本周/本月/本学期）
  - 导出班级考勤报表

- **学生考勤查询**
  - 输入学号或姓名查询个人考勤记录
  - 展示：考勤统计、异常明细、趋势图

**与学生详情联动：**

- 在学生详情弹窗中嵌入考勤概览卡片
- 显示：最近 30 天考勤状态、异常次数、本学期缺勤率
- 支持跳转到考勤明细页查看完整记录

#### 4.3.7 考勤统计指标

| 指标 | 计算方式 | 说明 |
|------|----------|------|
| 出勤率 | (实际出勤人次 / 应出勤人次) × 100% | 核心指标 |
| 缺勤率 | (缺勤人次 / 应出勤人次) × 100% | 反向指标 |
| 迟到率 | (迟到人次 / 应出勤人次) × 100% | 辅助指标 |
| 请假率 | (请假人次 / 应出勤人次) × 100% | 辅助指标 |
| 早退率 | (早退人次 / 应出勤人次) × 100% | 辅助指标 |

#### 4.3.8 导出功能

- **个人考勤记录导出**：按学号/日期范围导出 Excel
- **班级考勤汇总导出**：按班级/学期导出考勤统计表
- **异常考勤名单导出**：导出未处理或处理中的异常记录

#### 4.3.9 权限

- 访问角色：辅导员、管理员
- 数据可见范围：辅导员看本人负责班级的考勤，管理员可看全部
- 操作权限：辅导员可处理异常，管理员可全局查看和统计

#### 4.3.10 与打卡模块对接

**对接方式：**

- 提供考勤数据接入 API，打卡模块主动推送考勤数据
- 或由本系统定时拉取打卡模块数据
- 数据同步频率：实时或每日批量

**接口约定：**

| 字段 | 说明 |
|------|------|
| studentNo | 学号 |
| courseName | 课程名称 |
| attendDate | 考勤日期 |
| status | 考勤状态码（0-正常，1-迟到，2-缺勤，3-早退，4-请假） |
| checkInTime | 打卡时间 |

#### 4.3.11 Agent 接口预留（内部调用）

供 chat 模块中的 AI Agent 查询学生考勤记录：

| 接口 | 说明 | 可见性 |
|------|------|--------|
| GET /internal/attendance/{studentNo}/summary | 获取学生考勤摘要 | 内部 |
| GET /internal/attendance/{studentNo}/records | 获取学生考勤明细 | 内部 |

### 4.4 学业管理（预留）

|--------|------|------|
| 学号 | 学生学号 | 必填 |
| 帮扶教师 | 帮扶辅导员 | 必填 |
| 帮扶类型 | 学业困难/心理/就业 | 必填 |
| 帮扶内容 | 帮扶措施说明 | 必填 |
| 帮扶时间 | 帮扶日期 | 必填 |
| 跟进状态 | 待跟进/跟进中/已完成 | 必填 |

#### 4.4.3 基础看板

- 成绩总览：及格率、挂科数
- 学分绩点：累计学分、平均绩点
- 学业预警人数：按类型和等级统计
- 帮扶统计：帮扶人数、已完成数

- 与 chat 模块联动，agent 可查询学生学业状态

## 6. 非功能性需求

### 6.1 性能需求

- 学生列表查询响应时间 < 2s（万级数据量）
- Excel 导入支持千级数据量，单次导入 < 30s

### 6.2 安全需求

- 敏感信息（联系方式）按角色分级可见
- 发送给 AI agent 时自动脱敏
- 所有写入操作过风控校验
- 导出操作记录审计日志

### 6.3 扩展性需求

- 各模块数据模型独立，可按需扩展
- 异常规则、班辅映射、导出字段等预留可配置能力
- Agent 工具接口预留，支持 chat 模块调用
